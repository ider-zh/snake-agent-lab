# 首页播放与更名验收（2026-10-15）

## 复现与实现

在本机真实 Chrome（可见窗口、1440 × 1000）访问正式站点：系统默认与显式 no-preference 下，无交互分别从第 1 步到第 37 步、从第 0 步到第 36 步；reduce 下始终为第 0 步，播放按钮被禁用。旧域名与新域名均复现这些结果。该证据确认减少动画时缺少主动播放入口，不能据此断言用户的浏览器一定使用该偏好。

三种偏好都有 Cloudflare beacon 脚本 CSP 警告，但普通偏好仍持续推进，因此它是独立的统计脚本阻断。未修改 CSP、Pixi 静态 polyfill 或 Cloudflare 账户设置。

已实现：首页减少动画时默认静止并展示说明；允许主动播放与暂停，不改变系统设置。当前页面播放许可在动画偏好改变时清除，刷新或路由重新进入也不保留许可。可见性只控制计时器，手动暂停不会被前台恢复覆盖。核心规则、种子 42、8 × 8、5000 步/500 无食物步预算未变。
