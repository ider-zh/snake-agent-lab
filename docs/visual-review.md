# HP 视觉审查记录

> 最新主题按用户反馈统一为柔和深色，见 [本轮修正与同视口对照](soft-dark-review.md)。以下保留此前视觉迭代历史。

日期：2026-10-05。设计目标是具有辨识度、可操作、可读且可信的 SnakeLab 实验仪器。奖项是品质参考，不是本项目获得了奖项或外部认证的声明。

参考 [Webby 官方评审维度](https://www.webbyawards.com/judging-criteria/)：内容、导航、视觉、功能、互动、创新和整体体验。这里把它们转换为可检查的产品要求，不虚构奖项分数。

## 设计与证据

- 纸白工作台、墨绿仿真区域、酸橙主要游戏动作；细线、克制的小圆角和等宽数字保持实验仪器的识别度。
- 核心互动是暂停、单步、查看真实搜索路径、保存与核验回放。训练图表只绘制真实采样，支持指针和方向键查看数据，空状态不生成示意成绩。
- 桌面保留四个独立棋盘。手机显示一个大棋盘，并提供四策略的实时得分/步数摘要与切换；仿真仍同时运行四局。
- 手机规则设置可展开；运行、暂停和单步提前到棋盘上方。停止保留指标与冻结模型，完整续训仍需事先保存检查点。
- 操作焦点可见；说明弹窗有焦点循环、Esc 关闭及返回焦点；图标按钮有可访问名称；减少动态效果偏好关闭过渡和运行指示动画。

## 实际迭代

| 轮次 | 检查结果 | 修改 |
| --- | --- | --- |
| 基线 | 原深色界面大量小字与弱对比；手机四棋盘偏小；平板导航隐藏文本后失去名称；运行焦点可能滚动页面 | 保存桌面/手机截图和真实浏览器结果，记录问题 |
| 第一轮 | 1440/1024/820/390/320px 共15个画面无横向溢出或脚本错误；发现说明按钮与模式按钮不足44px、分隔符弱对比、手机选中策略悬停配色冲突；桌面控制位于棋盘下方 | 重构配色、字号与层级；新增可检查的数据图；移动竞技改为单大棋盘 |
| 第二轮 | 同15画面可见文字自动对比度、启用按钮44px与溢出检查全部通过，并目视检查桌面实验台/训练、手机竞技和320px训练 | 修复选中悬停、触控尺寸与对比度；控制移到棋盘上方；桌面棋盘按高度约束；手机参数折叠、训练指标两列；补充窄屏预算选项全宽与抽样棋盘暗色底 |

自动对比度检查计算 DOM 可见文本颜色及不透明祖先底色，普通文字目标4.5:1、大字3:1；它不是完整的 WCAG 认证，也不替代屏幕阅读器真人测试。Canvas 保留文字状态摘要；图表提供采样值和键盘检查。

## 重现

```sh
npm run check
npx playwright install chromium
npm run test:e2e
# 另一个终端先运行 npm run preview -- --port 4173
node scripts/visual-qa.ts qa-artifacts/visual
```

截图脚本覆盖1440、1024、820、390、320px的实验台、竞技和训练。输出完整页面、手机棋盘聚焦截图与 `audit.json`。本机保留 `qa-artifacts/baseline/`、`revision-1/`、`revision-2/` 和最终结果目录；原始报告不包含在生产构建中。

## 品质边界

已执行的是 HP 上 Chromium 的真实脚本、Canvas、Worker 与 IndexedDB 流程；手机是视口/触控模拟，不是实体 iPhone。Safari、Firefox、真实手机温度/耗电、长时训练、真人屏幕阅读器、真实用户 Web Vitals 和外部设计评审仍未验证。没有为视觉引入远程字体、装饰图片、第三方追踪或动画库，也不因短训练结果宣称算法优越。

最终功能测试与设备数据见 [HP 验证记录](hp-validation.md)。
