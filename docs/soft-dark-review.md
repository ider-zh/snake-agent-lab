# 统一柔和深色修正

用户反馈：纸白页面与深色棋盘同时出现，明暗反差过大。本轮只调整色彩、图表与棋盘绘制颜色，并修正审查发现的两个过小图标按钮；保留布局、算法和交互流程。

页面采用 `#242c28`，面板 `#29332d`，棋盘 `#27372d`。侧栏、输入框、表格、空状态、提示和弹窗使用接近的灰绿色深色层级，依靠边框、间距和文字区分。选中态为深绿填充，取消大面积荧光色；蛇、食物与策略仍保留可区分的小面积颜色。

## 可读性与视觉验证

代表色值按相对亮度公式计算：正文/面板 10.04:1，次级文字/面板 6.99:1，选中按钮文字 6.74:1，错误文字 6.28:1。焦点环对最亮按钮底色为 4.09:1。正文保留至少 4.5:1 的目标，并非通过降低文字可读性减小反差。

`node scripts/theme-qa.ts qa-artifacts/soft-dark-final` 实际执行 41 组浏览器页面/状态检查：1440、1024、820、390、320px 的实验台、竞技、训练、批量空状态、回放空/有数据状态和无效导入；桌面与手机另测真实批量结果表、帮助弹窗和不适用策略错误。DOM 文字对比度、可用按钮 44px、横向溢出、键盘焦点、减少动态效果及页面错误全部通过。[原始审查数据](qa/soft-dark/audit.json)。

截图已目视审查桌面实验台/竞技/结果表/错误状态、手机竞技/弹窗及 320px 训练页面。完整页截图中的固定导航只出现在采集时的视口位置；手机聚焦图用于检查棋盘是否被固定导航遮挡。

审查发现通知关闭按钮为 36px、手机回放重置按钮为 38–42px，已统一补足 44px。焦点探针同时覆盖 HTML 控件与可聚焦 SVG 图表。

本轮功能回归结果在提交前记录于 [HP 验证记录](hp-validation.md)。未执行实体手机、Safari/Firefox、真人屏幕阅读器验证；DOM 审查不等于完整 WCAG 认证或主观舒适度保证。

## 回归中的问题与处理

首轮完整浏览器回归为 17 项通过、1 项超时：手机批量导出测试按每局 2,000 步运行，等待 60 秒时截图显示任务仍在运行且进度接近完成。该测试的目标是验证 40 局结果导出与导入错误处理，现明确使用每局 100 步的有界工作量；没有提高超时或改动应用的默认预算、算法和 Worker。最终复跑结果见 HP 验证记录。
