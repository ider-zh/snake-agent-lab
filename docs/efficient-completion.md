# 保持环序的安全捷径：通关与效率验证

2026-10-06，HP。本实现独立编写，原 `hamiltonian` successor-only 策略保留为基线。新增 `hamiltonian-shortcut`，不是提高播放倍速，也不需要训练。

## 原先为什么慢、为什么会被截断

旧 Hamiltonian 始终只走环上的下一格，没有捷径。A* 仅寻找静态最短路，再做动态身体模拟和尾部/空间启发式检查，没有维护全局环序；得分提升不是填满证明。原实验台默认 12×12、初长 3、5000 总步，纯连续环在均匀空格食物下的期望总步数为 `(N-L)(N-L+3)/4 = 5076`，已经超过默认预算；最大可能总步数为 `(N-L)(N-L+1)/2 = 10011`。这是该纯环/连续初态/单食物协议的推导，不是实测成绩，也不适用于所有策略。

参考 [gargimahale 的 Hamilton 实现](https://github.com/gargimahale/Snake/blob/master/snake/solver/hamilton.py) 确实在占用率低于一半时尝试食物最短路的首步，并使用环索引限制越尾/越食物；我们的旧策略缺少这一层。[其 README](https://github.com/gargimahale/Snake/blob/master/README.md) 报告平均长度 63.93/64，而不是 100% 通关率，展示的 demo 标注为 optimal。不同初长和尾格碰撞语义不能直接横比。本文没有复制其代码，也没有把其成绩当本项目结果。[Dmitry 的 README](https://github.com/dmitryshelomanov/snake) 的默认多食物（50）和窗口相关棋盘也不是这里的单食物固定棋盘协议。

## 支持范围与不变量

- 固定矩形环：宽高均大于 1、至少一边为偶数、无障碍、`cycle` 初始化、初始身体至少 3 格。
- 按尾→头顺序，将各身体格的环索引转换为相对尾部的前向距离，必须严格递增，允许间隙。旧纯环的连续性判断不适用于捷径后的状态。
- 使用共用 `legalActions` 与 `simulateMove`，保持禁止反向、增长保尾、非增长释放尾格等规则。
- 候选必须是物理相邻格，沿环向前，且不得越过当前食物；模拟后必须仍然环序有序，且普通环后继动作仍合法（满盘除外）。
- 只有占用率低于 50% 才尝试捷径，选前向环距离最大的合格邻居；后半程沿环收紧身体。最多检查三个合法邻居，节点/时间预算到达时沿环回退。循环边界检查墙钟，单次身体检查无法在 JavaScript 指令内部抢占。

可维护性论证：每个接受的动作都精确检查下一状态的环序及后继，普通后继不跨越身体；非增长释放尾部后顺序仍保留，增长时保留尾部也经过检查。新食物不会生成在身体上，因此不会把原本允许释放的尾格变成吃食物增长碰撞。食物不变时，蛇头到食物的前向环距离严格减少；单次食物等待少于 N 步。足够预算下可逐个吃完有限空格。此论证限定于支持的状态与规则，不是任意障碍图、任意方向/身体导入或有限墙钟资源下的必胜承诺。

## 参数选择与独立对照

第一版全程开捷径虽然安全，但后半程身体间隙导致绕行，30 个开发检查种子仅节省约 4–6% 总步数；保留[原始试验](qa/shortcut/aggressive-pilot.json)。随后用开发种子 101–105 比较 0%、25%、50%、75%、100% 占用率阈值，三种尺寸均支持选 50%；见[占用率试验](qa/shortcut/occupancy-pilot.json)。

固定此阈值后，在另一组种子 **30001–30030** 对照。它们没有用于本次阈值选择，但此前项目训练报告使用过其中一些环境种子，因此不宣称是项目从未见过的数据。每策略每尺寸同种子、同初始身体、同环境 PRNG 规则、同预算；不同轨迹会改变可放食物位置，不保证后续食物坐标相同。

无障碍、有墙、单食物、初长 3、cycle 初始化。充足预算：总步 `N²`、无食物 `N`；产品预算对照：5000/500。研究脚本使用 10000 节点、无限决策墙钟保证动作可重现，每局另有 120 秒资源上限；未将 Infinity 传入批量接口。原始每局日志、失败填充率、成功局 median/p95、配对步差和捷径次数均在[完整报告](qa/shortcut/benchmark.json)。

## 产品与验证

实验台支持新策略、20×20，以及明确可取消的“充足通关预算（N²）”；两个环策略采用同样规则。关闭该选项恢复原 5000/500 预算。批量 UI 提供 N² 快捷填入，两个环策略同属 cycle 协议组，JSON 导入验证认识新 ID。DQN/GA 参数、训练 Worker、模型格式未改。

实验台通关选项实际采用 `max(5000,N²)` 与 `max(500,N)`，避免把小棋盘原预算缩短。长对局得分图只保留数值序列，不再存每一步完整身体快照；回放仍保留动作。现有回放文件上限 50000 动作不变，超过时明确拒绝导出；本次测得的所有完整对局均在其内。这个限制不等于 160000 步通关预算内任意轨迹都可导出。

新增第 12 课解释安全条件和占用率阈值，双语环距离程序明确只是构件。完整 check 已通过：101 项单测、lint、typecheck、生产构建。性质测试覆盖 4×4、6×4、5×4 转置环、8×8 多种子状态与最终填满；3×2 枚举物理相邻有序身体、食物位置；预算耗尽与 batch 导出重验均通过。浏览器最终验收结果后补。

DFS、Dijkstra、Beam、MCTS、Q-learning、SARSA、PPO、模仿学习等后续任务尚未因本次捷径实现而自动完成；优先级按用户要求调整为先验证通关质量。
